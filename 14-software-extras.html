Software extras

Themes, apps, libraries, and SD packs for Bruce and the Flipper-style port. Everything lives on the FAT32 card.

Bruce

Themes

  • Place the theme folder (the .json plus its images) in /Themes/ on the SD card or in LittleFS.
  • Apply: Config → UI Theme → choose the filesystem → select the .json.
  • Recommended image height for the T-Embed screen is about 140 px. Keep images small.

Community sources: anonimoKali/Bruce-Themes, Ghoststrats/GhostStrats-Bruce-Themes.

Apps and JavaScript scripts

  • Install the App Store once: Config → Install App Store (needs Wi-Fi).
  • Then open it from JS Interpreter → Tools → App Store.
  • Manual install: put .js files in /BruceJS/<Category>/.

Only run scripts whose source you can read.

Flipper-style port (Sor3nt)

The .bin alone boots an empty interface. You need the matching asset pack.

  1. Download the latest sdcard.zip from the project releases.
  2. Extract the contents (not the zip folder itself) to the root of a FAT32 card.
  3. Insert the card and reboot.

Extra things you can add: more BadUSB scripts in /ext/badusb/, custom dolphin animations, your own captures (Archive organises them).

Desktop companion: qT-Embed.

Pre-recorded community packs

These are the main collections of Sub-GHz .sub files, IR codes, and BadUSB scripts. Most work on both firmwares (drop .sub / .ir / BadUSB scripts onto the card).

How to add them:

  1. Download the folders or files you want from the repos above.
  2. Copy to the SD card (BadUSB → /ext/badusb/ on Flipper port; .sub and .ir anywhere).
  3. Reboot and open the matching app (Sub-GHz, IR, Bad USB, Files / Archive, or Bruce Custom SubGhz / Custom IR).

Only use signals and scripts on devices, remotes, tags, and networks you own or have permission to test.
