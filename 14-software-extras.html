Software extras

Themes, scripts, and signal packs.

Everything lives on the FAT32 card. Most collections work on both Bruce and the Flipper-style port.

Regional frequencies (Sub-GHz)

Your CC1101 covers roughly 300–348, 387–464, and 779–928 MHz. Transmit only on bands legal where you are.

RegionCommon bandsTypical devices
EU / Europe433.92 MHz, 868 MHzGarage doors, gates, doorbells, sensors, weather stations, older car fobs
US / North America315 MHz, 433.92 MHz, 915 MHzGarage doors (Chamberlain/LiftMaster often 315), car fobs, sensors
Australia / NZ433.92 MHz (main), some 915 MHzMost garage doors, gates, and car fobs. Similar to EU on 433.

Bruce

Themes

  • Put the theme folder (.json + images) in /Themes/.
  • Apply: Config → UI Theme → select the .json.
  • Sources: anonimoKali/Bruce-Themes, Ghoststrats/GhostStrats-Bruce-Themes.

Apps and scripts

  • Install App Store once: Config → Install App Store (needs Wi-Fi).
  • Then: JS Interpreter → Tools → App Store.
  • Manual: .js files in /BruceJS/<Category>/.

Packs: Official sd_files · Bruce Hub · sloth632 · tebin623 · 3xp-l01t

Flipper-style port (Sor3nt)

The .bin alone boots an empty interface. You need the matching asset pack.

  1. Download the latest sdcard.zip from the project releases.
  2. Extract the contents to the root of a FAT32 card.
  3. Insert and reboot.

Desktop companion: qT-Embed.
