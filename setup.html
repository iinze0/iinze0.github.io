Full setup, in order.
Do this once.

Follow these steps. Everything else is optional after this.

  1. Read the rules. Own hardware only. Legal.
  2. Know your board. Plus has the nRF24. External antenna (K268-01) is easier to swap. Hardware · Buy.
  3. Prepare the card. FAT32, 8–32 GB. Insert before first launcher boot. SD card.
  4. Flash one launcher. Not both. Install page.
    • loznoc dual-boot — best remote, 3 slots, themes
    • bmorcelli Launcher — catalog + OTA
  5. Put apps in slots. Copy .bin files to the card, then on the device: Install → file → slot → name. Suggested: 1 Bruce, 2 Flipper port (needs sdcard pack), 3 spare. Firmware index.
  6. Set the band. Before any transmit. EU: 433.92 or 868. US: 915. Australia: 433.92. Antenna must match. Antennas.
  7. Try the remote. Remote page — screen mirror and wheel control from your phone.
