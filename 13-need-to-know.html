Need to know

Short version of everything that matters on day one.

  • Flash one launcher (bmorcelli or loznoc). Not both.
  • FAT32 card, 8–32 GB, before first boot if you want slots.
  • Install apps into slots from the card. The browser does not install slots.
  • Remote is a page the board serves. Join its Wi-Fi.
  • Own hardware only. See legal.
