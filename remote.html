Your launcher, your phone

Remote control is a page the board serves.
Not this website.

This site cannot drive the encoder from the public internet. The launcher on the device opens a Wi-Fi page. Your phone joins that network, or the same LAN, and that page mirrors the 320×170 screen and injects the wheel and the side button. Flash the launcher first.

loznoc dual-boot

  1. Boot into the launcher. Open WiFi.
  2. First run is a hotspot. The screen shows the name T-Embed-XXXX, password dualboot, and http://192.168.4.1.
  3. Join it from the phone. Open that address. PIN first if you set one. The lock screen is not exposed on the network.
  4. SCREEN is the framebuffer. REMOTE is left, right, ok, and back — the same events as the wheel and the side button.
  5. To stay on your normal Wi-Fi, put that network in the NETWORK panel. It then answers at http://tembed.local as well as its address. Tick start-on-boot if you want it after reset.
  6. A .bin upload lands on the card. Install it on the device after. BACK leaves Wi-Fi up. Press turns Wi-Fi off.
Open 192.168.4.1 Open tembed.local

Those open only if this phone is already on the launcher’s network. Otherwise the browser will time out. That is expected.

If you script it

Same phone, same network, the launcher’s own HTTP. Not a public API.

  • GET /fb?s=1..4 — raw RGB565, width and height in headers
  • GET /key?k=left|right|ok|back
  • GET /cm?cmnd=nav prev|next|sel|esc — same names as Bruce’s WebUI
  • POST /bin — firmware onto the card
  • POST /theme — theme pack
