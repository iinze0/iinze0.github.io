Your launcher, your phone

Remote control is a page the board serves.
Not this website.

This site cannot drive the encoder from the public internet. The firmware on the device opens a Wi-Fi page. Your phone joins that network (or the same LAN) and that page mirrors the 320×170 screen and injects the wheel and the side button. Flash the launcher or app first.

loznoc dual-boot

Best remote for this board. Full screen mirror + wheel control + file upload.

  1. Boot into the launcher. Open WiFi.
  2. First run is a hotspot. The screen shows the name T-Embed-XXXX, password dualboot, and http://192.168.4.1.
  3. Join it from the phone. Open that address. PIN first if you set one. The lock screen is not exposed on the network.
  4. SCREEN is the live framebuffer. REMOTE is left, right, ok, and back — the same events as the wheel and the side button.
  5. To stay on your normal Wi-Fi, put that network in the NETWORK panel. It then answers at http://tembed.local as well as its address. Tick start-on-boot if you want it after reset.
  6. Upload a .bin (lands on the card — install it on the device after) or a theme pack. BACK leaves Wi-Fi up. Press turns Wi-Fi off.
Open 192.168.4.1 Open tembed.local

Those open only if this phone is already on the launcher’s network. Otherwise the browser will time out. That is expected.

Scriptable endpoints (same network only): GET /fb?s=1..4 (raw RGB565), GET /key?k=left|right|ok|back, GET /cm?cmnd=nav prev|next|sel|esc, POST /bin, POST /theme.

bmorcelli Launcher

Web User Interface for files, OTA, and partition tools. No full screen mirror, but strong file and install control.

  1. Boot into the launcher. Open WUI.
  2. The screen shows the IP (or http://launcher.local on some builds). Default login is often admin / launcher.
  3. From the browser you can browse the SD card, upload files or folders, download, delete, rename, and install a .bin already on the card.
  4. OTA tab lets you upload and install firmware directly. Partitions tab matches the on-device PMan tools.
  5. Config lets you change Wi-Fi, WebUI password, and other settings.

The flasher is on the install page. See the Launcher wiki for the full WebUI layout.

Bruce

Bruce has its own WebUI with a Navigator for screen control and file management. Works when Bruce is running (alone or in a slot).

  1. In Bruce: Files → WebUI.
  2. Choose My Network (join your Wi-Fi) or AP Mode (device creates a hotspot).
  3. Open http://bruce.local or the IP shown on screen. Default credentials are often admin / bruce.
  4. The Navigator button shows a live view and on-screen buttons for navigation, select, long press, and back.
  5. You can also browse SD / LittleFS, upload, download, run .ir / .sub / .js files, and send serial commands.

Docs: Bruce WebUI wiki.

Flipper-style port and others

The Sor3nt Flipper ESP32 port and most other slot apps do not ship a full remote page of their own.

  • Use the launcher remote (loznoc or bmorcelli) to manage files and switch slots.
  • Once inside the app, control is on the device itself.
  • Some ports expose a simple web file browser if you enable it in their settings.
  • For Bruce inside a slot, use Bruce’s own WebUI as above.

If an app has no remote, the launcher is still the way to drop files onto the card and reboot into the right slot.
